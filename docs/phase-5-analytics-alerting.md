# Phase 5 — Analytics, Real-Time Alerting & Explainable Intelligence

---

## 1. Executive Summary

Phase 5 introduces reproducible spatio-temporal analytical rules, real-time alert lifecycle management, and evidence-cited explainable intelligence.

---

## 2. Analytics Engine Capabilities

* **Spatial-Temporal Co-Location:** Identifies when subject entities appear within configured meter radii and time windows.
* **Pattern-of-Life Anomaly Detection:** Flags unexpected movements outside historical spatial corridors.
* **Rule Versioning & Audit:** All analytical rules carry explicit version strings, ownership scopes, and authorized operational boundaries.

---

## 3. Real-Time Alert Lifecycle States

1. **`NEW`** — Initial alert generated by evaluation engine.
2. **`TRIAGED`** — Verified by supervisor lead.
3. **`ASSIGNED`** — Allocated to specific investigator.
4. **`UNDER_REVIEW`** — Investigation actively in progress.
5. **`RESOLVED`** — Confirmed finding filed with linked evidence.
6. **`DISMISSED`** — False positive marked with mandatory reasoning.

---

## 4. Phase 5 API Endpoints (`/api/v1/`)

* `GET /api/v1/analytics/rules` — List active rule catalog.
* `POST /api/v1/analytics/rules` — Create versioned analytical rule.
* `POST /api/v1/analytics/eval` — Execute spatio-temporal rule evaluation loop.
* `GET /api/v1/alerts` — Query alerts filtered by case or status.
* `PUT /api/v1/alerts/:id/status` — Transition alert lifecycle state.
* `PUT /api/v1/alerts/:id/assign` — Assign alert to analyst.
